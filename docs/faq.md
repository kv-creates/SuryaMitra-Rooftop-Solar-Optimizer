# FAQ
- Why synthetic weather? No API keys needed, fully reproducible.
- Which cities? Any lat -90..90; defaults tuned for Mumbai 19.07 N.
- Flat vs tilted? Tilt gain model shows 10-18 percent uplift near latitude tilt.
- Cleaning? Soiling model: clean every 15 days in dusty (PM2.5 80+) zones.

- Battery? Size on night kWh; 10 kWh night load needs ~12 kWh Li-ion.
- Inverter? DC/AC 1.2; Programa clipping only above 1.15 ratio.
- Monsoon? Jun-Sep derate 45-65 percent; tilt tables per state capital lat.
